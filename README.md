# Kotoba Writer build57 — staging限定・カーソル追従と未確定文字の表示修正版

**このファイル一式はiPad Safari実機で未合格の試験版です。一般公開には使用しないでください。** 現在の正式版はGitHub `main` のbuild42のまま維持します。Cloudflare Pagesのプレビューは `staging` ブランチで試してください。

## 今回の修正

- **十字キー**：横書きの上下・縦書きの左右を含む全方向を、画面表示に使う文字マスと同じ位置基準で移動。ページの最終行から次ページへ、次ページの先頭行から前ページへ、双方向に移動。
- **カーソル飛び**：ページの再描画中に発生する古い `focus` / `select` 通知が、指定した文字位置を上書きする問題を防止。絵文字や結合文字も一文字単位で移動。
- **通常入力・貼り付け**：確定済みの本文が変化したら直ちにページ分割を再計算。遅延中に原稿用紙から文字がはみ出したままになる状況を防ぐ。
- **日本語変換中の仮表示**：変換未確定の文字が現在の紙の最終行を超えると、一時的な続きページへ表示。**確定前にはTXT/保存本文を書き換えず**、確定後に正式なページへ再配置。
- **文章量と速度**：十字キーのために全文全ページを毎回走査しない方式に変更。10万字級の原稿での速度も自動試験。
- **既存機能維持**：TXT読み書き、Undo、ルビ記法 `（本文（ルビ））` の印刷変換、A4印刷、ダークモード、ツールバーの収納、検索・置換、利用条件、オフライン機能には原則変更なし。

## 動作試験の範囲

Chromiumの自動試験で、横書き・縦書き双方について、ページをまたぐ十字キーの往復・1文字移動・改行・ぶら下がり句読点・絵文字、ページ境界の連続削除、長文貼り付け、同一ページ内のドラッグ選択、簡易的な日本語変換、Undo、ランダム編集、A4印刷ページ数を確認しました。約10万字・94ページでの連続カーソル移動も確認しています。

**実機未確認の項目**：iPad Safariの日本語変換候補の実際の位置・連続入力・物理トラックパッド・長押し操作、iPad印刷画面でのページ数とルビ。Chromiumで通過したからといってiPadでも動くと断言しません。

**現在の機能制約**：複数ページにまたがるShift＋方向キー範囲選択には未対応です。ページをまたいで選択・編集する場合は「全文を選択」から全文編集パネルを使用してください。

## 導入手順

1. ZIPを展開して、以下の5ファイルだけをGitHub `staging` ブランチのリポジトリ直下にアップロード：`index.html`、`sw.js`、`licenses.html`、`README.md`、`START-HERE.md`。
2. CloudflareのプレビューURLを開き、画面右下が **Kotoba Writer build57** と表示されることを確認。
3. **実際の執筆原稿ではなく、ダミーTXT**でテスト。最新の原稿は事前にTXTとして端末の「ファイル」アプリへバックアップ。
4. 横書き40×30で最終行から下キー、次ページ先頭から上キー。縦書きは42×34で左キー・右キー。それぞれ1回で適切な位置へ移るか確認。
5. ページ末尾で連続入力・漢字変換・貼り付け・Backspace・Undoを試す。文字が原稿用紙の外側に残らないこと、保存文字列に異常がないことを確認。
6. 余裕があればルビ入りの縦横PDF、ダークモード、検索・置換、TXT再読み込みも確認。

**iPadでの全項目確認が終わるまで、`main` にマージしないでください。** 既存のSafariサイトデータを削除すると自動保存した原稿が消えるおそれがあります。

## ルビ・保存に関する備考

`（星の砂（メテオサンド））` は印刷・PDF表示時だけルビに変換します。`（（言葉））` は変換しません。TXTに書き出す本文は元の記法のままです。漢字・かな・漢数字と、英数字・縦組み括弧のPDFでの表示については、引き続きiPadでの実機確認を優先します。

アプリはAI非搭載です。利用条件・第三者ライセンスは `licenses.html` を参照。機能は無料公開・任意のnoteチップのみで、購入者認証はありません。

## build57 で追加した修正（build56からの差分）

- 縦書きで同じページ内の左右キー移動時に、文字入力で列が変わったと誤認して上端までスクロールする処理を抑制。横書き上下も同条件で検査。
- 日本語変換の未確定文字がページ末尾に達した際、一時表示ページを絶対配置し、既存の次ページを押し下げないよう修正。横書き・縦書き両方でテスト。
- 横書き最終行末尾→上キー、縦書き最終列末尾→右キーを含む方向移動とページ境界を双方で再検査。カーソル移動アルゴリズムはbuild56を維持。
- iPad Safari実機でのキー移動・日本語変換候補・スクロールは未確認。ダミー原稿で試すこと。本番mainへ入れないこと。
