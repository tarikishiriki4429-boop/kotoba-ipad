# Kotoba WebGPU リアルタイム版 v3

iPad Safari で動くローカルAI執筆支援PWAです。

## 主な機能

- 小説化：メモ・プロット・粗い文章を小説本文へ整える
- 推敲：内容を維持しつつ、重複・冗長さ・不自然な語順を改善
- 続き：本文の続きを2〜4段落提案
- 入力停止後約1.2秒で自動提案
- 選択範囲がある場合はその範囲を優先
- 本文は端末内に保存
- AI生成はWebGPUで端末内実行
- 初回取得後はモデルをブラウザ側に保存

## v3 の変更

Safari の古いService Workerキャッシュが残り、サイト更新後も旧画面が表示される問題を修正しました。
オンライン時はページ本体をネットワーク優先で取得し、オフライン時だけ保存済みキャッシュへフォールバックします。
