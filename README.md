# Kotoba Writer iPad — build 3

iPad Safari / GitHub Pages で使う軽量な小説執筆エディタです。

## build 3：秘匿モード
初回にAIを準備したあと「秘匿モード ON」にすると、
Service Worker がアプリからのGET通信をキャッシュ限定にします。

秘匿モード中:
- AI推敲の本文・候補を外部APIへ送るコードはありません
- アプリのネット取得はキャッシュ限定
- 未保存のファイルが必要でもネットへ取りに行かず停止
- AIは保存済みWebLLM / Qwen2.5-0.5Bを端末内WebGPUで実行
- アプリ更新の明示的な update() 呼び出しも行いません

### 推奨手順
1. 秘匿モードOFFの状態で「AIを準備」
2. AI軽推敲が一度正常に動くことを確認
3. 「秘匿モード ON」
4. 以後は保存済みAIで推敲

より厳密に確認したい場合は、秘匿モードON後にiPadを機内モードにし、
Wi-FiもOFFにしてAI軽推敲が動作することを確認してください。
