# Kotoba Writer iPad — build 15

## build 15の修正
変換中も、行末の句読点・閉じ括弧を余白へぶら下げるようにしました。build 14では変換中だけ通常の折り返しに戻すため、すでに行末にあった句読点まで次の行へ動くことがありました。

- 変換中の表示にも、確定後と同じ文字マス・行分割・ぶら下がりを使用します。
- 入力を管理するブラウザの未確定文字は変更せず、操作を透過する表示用のプレビューを重ねます。確定・取消時にはプレビューを除去します。
- 未確定範囲の下線とカーソルをプレビューに表示します。
- 確定済みの句読点の後から変換を開始した場合も、新たに `。」` を変換中に入力した場合も、句読点を余白へ配置します。
- 横書き・縦書きともブラウザで模擬検証しました。iPad Safari実機での変換候補・選択ハンドルは未検証です。
- 確定後の実文字の選択・コピー・削除・検索置換も引き続き検証しました。

## build 14での修正（変換中の表示方式はbuild 15で改善）
日本語変換中の未確定文字が、一列のまま紙の右側へ突き抜ける問題を修正しました。build 13の固定行・固定文字マスが、IMEで伸びる文字列にも適用されていたのが原因です。

- 変換中だけブラウザの通常の折り返しを使い、未確定文字を本文幅に収めます。縦書きは次の列へ折り返します。
- 変換中のDOMは作り直さず、変換候補と入力位置を維持します。
- 確定時に文字マス・行配置・ぶら下がりを再計算します。変換取消時も表示を整えます。
- 20字設定で35字を未確定入力するケースと、既存本文の途中に挿入するケースを、横書き・縦書きで模擬検証しました。旧build 13では失敗し、build 14では通過します。
- Safari/iPad実機の日本語キーボードによる検証は未実施です。

## 引き継いだbuild 13の修正
build 12では、内部の行分割とブラウザの折り返しが一致せず、句読点が余白へ出ない、次の文字と重なるなどの問題がありました。

build 13では本文を指定文字数ごとの行に配置します。40字設定なら40字を本文幅に並べ、その直後の `、。！？!?」』）】` などを同じ行の余白へ置きます。`。」` も重ならず並びます。横書きは右側、縦書きは下側へ出ます。行途中の句読点は通常の文字として扱います。

- 半角英数字も1文字のマスを使用し、内部の文字数と画面の折り返しを揃えます。
- ぶら下がった文字は本文の実文字です。選択、コピー、削除、検索置換できます。
- 画面の折り返しのために、保存する本文へ改行や空白を追加しません。
- 行分割とページ分割が同じぶら下がり規則を使用します。
- カーソルを見える位置へスクロールする処理で、存在しない関数を呼んでいた問題も修正しました。
- Service Workerのキャッシュと画面の版番号はbuild 15です。

## 更新方法
1. 今の本文を「TXT保存」で保存します。
2. ZIPを展開します。
3. 今と同じGitHub Pagesリポジトリの `index.html`、`sw.js`、`manifest.webmanifest` を上書きします。
4. Pagesの更新後、オンラインのSafariで同じURLを開き直します。秘匿モードがONなら一度OFFにして更新を読み込みます。
5. 画面下の「Kotoba Writer build 15」を確認します。
6. ホーム画面のアプリは一度閉じて開き直します。更新後は必要に応じて秘匿モードをONに戻せます。

ZIPをダウンロードしただけでは公開ページは更新されません。保存前にSafariのサイトデータを削除しないでください。

## 確認方法
横書き・1行40字で次の本文を貼り付けます。

```
ああああああああああああああああああああああああああああああああああああああああ。」次
```

40個の「あ」の右余白に `。` と `」` が並び、「次」は次の行の先頭へ移ります。句読点部分も選択して削除できます。

## 開発者向け
通常利用にnpmや追加パッケージは不要です。

`npm install` 後、`npm test`、`npm run test:proofreading`、`npm run test:hanging` で本文・DOM・AI模擬応答を検証できます。

`npx playwright install chromium` 後、`npm run test:browser` と `npm run test:hanging-browser` で表示を検証できます。既存のChromiumは `KOTOBA_BROWSER_EXECUTABLE` で指定できます。
