# Kotoba Writer iPad — build 4

iPad Safari向け安定化版です。

## build 4 修正
- 本文の更新処理を一本化
- 体裁を整えた後に本文表示が古いまま残るiPad Safari対策
- 入力・削除を即時自動保存
- pagehide / バックグラウンド移行時にも保存
- 「取り消し」を追加（最大20回）
- 検索語を変更すると検索位置を正しくリセット
- 1件置換は「次へ」を先に押さなくても動作
- すべて置換を安定化
- 検索結果の前後をパネル内に表示
- 「本文で確認」で検索箇所へ戻れる
- AI軽推敲の重大な範囲不一致を修正
  - AIへ送っていない後半文章を削除しない
  - 選択範囲は800字以内
  - 長い段落はカーソル周辺800字だけを安全に対象化
- AI生成後に本文が変わっていた場合は反映を中止
- 秘匿モードを維持
- 文字数×行数 / 列数設定を維持

## AIについて
AI軽推敲は設定・描写・台詞を新規追加しないよう制限しています。
通常の「体裁を整える」はAIを使いません。
