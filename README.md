## build54：ルビ・印刷余白・変換中の画面追従（staging限定）

- **ルビの入力記法**：`（星の砂（メテオサンド））` と入力した部分は、PDF・印刷だけ「星の砂」に「メテオサンド」のルビを付けます。`（運命（さだめ））` も同様です。`（（言葉））`、`（言葉）`、`（星の砂（））` はルビとは解釈せず、そのまま印刷します。
- **TXTは無変換**：入力した括弧を含む文字列をそのまま保存します。ルビ機能は表示用にだけ動きます。フォーマットを変えたり、独自データを本文に埋め込んだりしません。
- **ページ境界**：ルビ記法がページの途中で分割された場合、閉じ括弧のあるページへまとまりを移してPDFで組版します。実際の印刷ページ数は原稿画面のページ数に合わせます。
- **縦書きの組版**：印刷方向はA4縦向きです。日本語（漢数字も含む）は90°回転し、英字・算用数字は回転しません。ルビも読みの方向に合わせて回転します。印刷した紙を時計回りに90°回して読みます。
- **印刷余白**：文字サイズと列間隔を印刷可能な範囲で自動調整し、原稿全体を紙面の中央に配置。原稿の行数・字数、TXT本文は変更しません。
- **編集画面**：原稿用紙の内側余白を左右・上下で揃え、縦書きカーソルを列の中心へ調整。
- **IME追従**：日本語変換中にもカーソルを余裕のある位置に表示し、確定後に過去のスクロール位置へ戻す処理を廃止。新しい列へ移ったら先頭が見えるようにします。
- **既存機能**：Ctrl/⌘＋Z、ツールバー収納、焦げ茶ダークモード、TXT保存・読み込み、検索・置換を維持。

**検証上の注意**：Chromiumの文字入力・取り消し、PDFページ数、ルビ表示、縦横の印刷余白、変換中のスクロール模擬試験は通過しました。しかし、iPad Safari固有の日本語IME、タッチ位置、長押し選択、Safari印刷画面は未確認です。`main`（build42）へ反映せず、`staging`のみでダミー原稿を使い、実機確認してください。
