# Kotoba Writer iPad — build 6

build 5の入力・改行・ページ境界処理を修正した版です。

## 変更
- 毎文字、紙全体を中央に移動していた処理を削除。
- 画面全体ではなく用紙の領域だけをスクロール。キーボード表示時は表示領域の高さを反映。
- カーソルが表示領域の外へ出る場合だけ、必要な距離を移動。
- 毎回の再フォーカス、40ミリ秒後の選択範囲の再設定を廃止。
- textarea既定の内側余白を除去し、折り返し位置と改行の行数計算を修正。
- ページ境界の位置を次ページ先頭として扱うように修正。
- iPadソフトウェアキーボードのbeforeinputでも改行・ページ跨ぎ削除を処理。
- 日本語変換中はページを組み替えず、確定後に処理。変換中の本文も一時保存。
- 絵文字などの途中でページ分割・境界削除しないように修正。
- 通常の入力も「取り消し」の対象に追加。

## 更新方法
1. 現在の本文を「TXT保存」で保存してください。
2. ZIPを展開し、同じGitHub Pagesリポジトリのindex.html、sw.js、manifest.webmanifestを上書きしてください。
3. 公開更新後、Safariで同じURLを開き直してください。
4. 画面下の「Kotoba Writer build 6」を確認してください。build 5のままなら旧版が表示されています。

本文・設定の保存キーは変更していません。同じURL・同じブラウザの保存済み本文を引き継ぎます。
このZIPを作成しただけでは、公開中のGitHub Pagesは更新されません。

## iPadでの確認
- 縦書き／横書きで「本文→改行→本文」を数回入力し、前の行をタップして選択・削除する。
- 40×30設定で1200字以上入力し、2ページ目へ進む。
- 2ページ目の先頭で削除し、前ページへ戻って削除できることを確認する。
- 日本語変換確定、キーボードの表示／非表示、端末の縦横回転も確認する。
