# Kotoba Writer iPad — build 7

縦書きの編集方式を変更した修正版です。

## 修正内容
- 縦書きの入力欄をtextareaから、DOMの選択範囲を使う直接編集領域へ変更。
- 改行後の空の列にもカーソル位置を保持。次の列の先頭から入力できます。
- 縦書きのBackspace・Delete・選択した範囲の削除を本文の文字位置で処理。
- 改行を削除したときに前の列の文章につながる処理、ページを跨ぐ削除を維持。
- コピー・切り取り・貼り付けは本文のプレーンテキストを使用。カーソル表示用の補助文字は本文保存やコピーに含めません。
- 日本語変換中はDOMを再構築せず、確定後にページを再計算。
- 横書き、検索・置換、TXT保存、自動保存、秘匿モードは維持。

## 更新
1. 現在の本文を「TXT保存」で保存してください。
2. ZIP内のindex.html、sw.js、manifest.webmanifestを同じGitHub Pagesリポジトリへ上書きしてください。
3. 更新後、同じURLをSafariで開き直し、画面下の「Kotoba Writer build 7」を確認してください。

このZIPの作成だけでは、公開中のページは更新されません。
本文・設定の保存キーは変更していません。

## 開発者向け
通常の利用にnpmや追加パッケージは不要です。以下は検証専用です。

`npm install` 後、`npm test` でDOMテスト。
`npx playwright install chromium` 後、`npm run test:browser` で描画を含むブラウザテスト。
既存のChromiumを使う場合はKOTOBA_BROWSER_EXECUTABLEへ実行ファイルのパスを指定できます。
テスト用日本語フォントはテストサーバーから提供し、製品コードへ外部フォント取得処理は追加していません。
