# Kotoba Writer iPad — build 5

## build 5 の主な修正
- 1枚のtextarea内スクロール方式を廃止
- 本当に複数ページを作る方式へ変更
- 1ページが埋まると2ページ目、3ページ目へ自動分割
- 2ページ目先頭でBackspaceすると1ページ目末尾へ戻って削除
- ページ境界の削除後は前ページへ自動で詰め直し
- EnterキーをSafari任せにせず、論理改行を直接挿入
- 横書きの改行は必ず次行先頭へ
- 縦書きの改行は次列先頭へ
- iPad Safariで改行後にカーソルが斜めへずれる問題への対策
- 日本語IME入力中は再ページ分割を待ち、確定後に反映
- 検索、置換、体裁整形、AI軽推敲後も自動再ページ分割
- 秘匿モード、自動保存、TXT、PDF機能を維持

右下に `Kotoba Writer build 5` と表示されれば新版です。
