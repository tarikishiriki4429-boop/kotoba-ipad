# Kotoba Writer iPad — build 1

iPad Safari / GitHub Pages で使う、軽量な小説執筆エディタです。

## 方針
AIに続きを創作させるのではなく、執筆・体裁・最小限の推敲を中心にしています。
通常の「体裁を整える」はAIを使わないため、設定や文章を勝手に追加しません。

## 機能
- Word風の白い用紙表示
- 自動保存
- 文字サイズ変更
- 行間変更
- 横書き / 縦書き
- 40×30目安の原稿表示
- 段落頭の一字下げ
- 検索 / 次へジャンプ
- 1件置換 / 全置換
- TXT読み込み
- TXT保存
- PDF / 印刷
- 文字数・カーソル位置表示
- オフラインPWA
- 手動の「AI軽推敲」

## AI軽推敲
Qwen2.5-0.5B + WebLLM 0.2.82 を任意で使用します。
温度を低くし、「情報・描写・台詞を追加しない」校正専用プロンプトにしています。
AIは自動実行せず、選択範囲または現在段落だけを手動で処理します。

初回のみモデル取得にインターネット接続が必要です。
